MyCatatan
Aplikasi catatan harian sederhana berbasis Flutter untuk menyimpan ide, rencana, pekerjaan, dan catatan penting dalam satu tempat.

Fitur
- Splash screen dengan animasi
- Login statis tanpa autentikasi atau backend
- Beranda dengan pencarian langsung dan filter kategori
- Tambah, edit, arsipkan, dan hapus catatan
- Data dummy
- Tampilan Material Design 3 yang responsif
